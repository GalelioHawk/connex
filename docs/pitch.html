Product

Real-time Messaging LIVE

Supabase Realtime WebSocket delivery. Message ticks (sent → delivered → read). Group chats, 1:1 messaging, camera integration.

🔔

Push Notifications LIVE

Firebase FCM integration. Instant delivery for new messages and SOS alerts, even when app is closed.

🔐

Secure Authentication LIVE

Phone number + password auth via Supabase. JWT session management, auto token refresh, persistent login.

🌗

Dark / Light Theme LIVE

Full dark and light mode with one-tap toggle. Persisted across sessions. Complete UI coverage.

Cross-platform LIVE

Built with Expo React Native — single codebase ships to both Android and iOS simultaneously.

Scalable Backend LIVE

Express + Supabase PostgreSQL + Redis caching. Designed for millions of concurrent users from day one.

Go-to-Market

Grassroots first. Schools and communities as the wedge.

Phase 1 — Launch

Community Seeding

  • Target matric students — free edu content as the hook
  • Partner with schools across Africa for initial distribution
  • WhatsApp group sharing as primary acquisition channel
  • Load shedding alert utility drives organic daily opens
Phase 2 — Growth

Neighbourhood Networks

  • Community alerts create neighbourhood-level retention
  • Township and suburb WhatsApp groups as distribution
  • SOS feature shared virally through word of mouth
  • Influencer partnerships with SA content creators
Phase 3 — Scale

Pay Unlocks Everything

  • Connex Pay turns the user base into a transaction network
  • Merchant onboarding — spaza shops, informal traders
  • Corporate partnerships for bulk alert distribution
  • Expand across East, West, and Central Africa — same infrastructure pain, same need
